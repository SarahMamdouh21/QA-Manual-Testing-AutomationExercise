# Manual Testing Project — AutomationExercise

## Overview
Manual testing project for the AutomationExercise e-commerce website. Test cases were organized and managed in Jira with Zephyr Advanced.

**Application under test:** https://automationexercise.com/

## Scope
- Authentication (login and registration)
- Contact Us form
- Test Cases page
- Products and product details
- Product search
- Newsletter subscription
- Shopping cart (add/remove products)

## Tools
- Jira
- Zephyr Advanced

## Testing Activities
- Test case creation and organization
- Preconditions, objectives, steps, and expected results
- Test cycle organization
- Test execution using Zephyr Test Player

## Test Summary
- 11 test cases designed and executed in Jira with Zephyr Advanced
- Execution result: 11/11 passed (100%)
- No defects were reported during this test cycle
