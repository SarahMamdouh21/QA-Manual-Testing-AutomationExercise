# Manual Testing – AutomationExercise

## Project Overview
This project focuses on manually testing an e-commerce web application to verify its main functionalities and identify potential issues.

**Application Under Test:** AutomationExercise  
**Website:** https://automationexercise.com/

## Scope of Testing
- User Login
- User Registration
- Product Browsing
- Functional Testing
- Positive and Negative Scenarios

## Testing Activities
- Test Case Design
- Test Execution
- Expected vs. Actual Result Validation
- Pass/Fail Status Documentation

## Tools
- Jira
- Zephyr

## Project Deliverables
- Test Cases
- Test Execution Results
- Test Evidence (Screenshots, where applicable)

## Project Status
Test cases were designed, executed, and their results were documented.

## Disclaimer
This project was created for educational and testing practice purposes.
